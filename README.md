# CLW: The Changing Tracks

Academic multimedia journalism website on concerns around production change and privatisation debates at **Chittaranjan Locomotive Works (CLW)**, Chittaranjan, West Bengal.

## Live site (exact local design)

**https://clwbyag.github.io/**

Repo: https://github.com/clwbyag/clwbyag.github.io

## Open locally

Double-click **`index.html`**  
or from PowerShell:

```powershell
Start-Process c:\Users\sayan\Desktop\tua\index.html
```


## Site map

| File | Section |
|------|---------|
| `index.html` | Homepage — hero, intro, featured stories |
| `the-story.html` | Connected narrative |
| `history.html` | History of CLW |
| `changing-tracks.html` | Production change |
| `voices.html` | Interviews + audio + transcripts |
| `multimedia.html` | Video + audio hub |
| `photo-story.html` | Photo essay |
| `data-story.html` | Charts / timeline placeholders |
| `about.html` | Project methodology |
| `stories/*.html` | Five featured story pages |
